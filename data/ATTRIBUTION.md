# Public interview bank

The vendored archive contains 103 questions and reference answers from **30-seconds/30-seconds-of-interviews**, revision `da235b6185721161b7ebc413075b76dc70339ccf`. The active bank uses 92 theory questions from it. Eleven coding and output-tracing prompts are retired. Two Node.js questions have shorter, code-free wording and retain their original citations.

- Repository: https://github.com/30-seconds/30-seconds-of-interviews
- Data: https://github.com/30-seconds/30-seconds-of-interviews/blob/da235b6185721161b7ebc413075b76dc70339ccf/data/questions.json
- License: MIT; the unmodified notice is retained in `public/LICENSE-30-seconds.txt`.
- Source markdown locators are retained for every Q&A. Text is normalized for display; role mappings and deterministic follow-up templates are Placement AI additions, not quotations from the source.
- Downloaded and license-checked through the GitHub API on 2026-11-16. The vendored revision makes local setup independent of later repository changes.
